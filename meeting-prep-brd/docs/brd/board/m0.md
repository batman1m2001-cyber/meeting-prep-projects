## Goal

meeting-prep-brd is the course brief's meeting-prep assistant on OperonX. A new customer email goes through six LLM agents, each limited to its own MCP tools through a 6-step tool harness, and ends in a brief waiting for a person's approval; after approval the brief is sent to sales and saved to the KB and memory. A golden eval of 19 emails gates quality at 90%.

### C3 · The six agents on AgentOp · done

- Intent: Each agent is an Agent spec with its own prompt, tools, turn limit and checked answer
- Rows: MPB-REQ-AGENT-01, MPB-REQ-AGENT-02, MPB-REQ-AGENT-03, MPB-REQ-AGENT-04, MPB-REQ-AGENT-05
- Files: src/agents/, src/agents/_shared/
- Criteria:
  - Six agents, one plain step, one person.
  - each agent ... a loop until it answers with its structured output, which its own op checks; a bad answer is an error, never a default.
  - Turn limits: the same per agent. On the last turn the model must answer.
  - Parallel calls: a turn's tool calls still run in parallel.
  - harness_tools(identity) builds one tool per scoped tool (scopes.yaml) ... A live test checks they equal what the running servers list.

### C4 · Six-step tool harness · done

- Intent: Validate, authenticate, authorize, rate-limit, audit and execute every tool call
- Rows: MPB-REQ-HARN-01, MPB-REQ-HARN-02, MPB-REQ-HARN-03, MPB-REQ-HARN-04, MPB-REQ-HARN-05, MPB-REQ-HARN-06, MPB-REQ-HARN-07, MPB-REQ-HARN-08
- Files: src/agents/_shared/_scopes.py, src/agents/_shared/scopes.yaml, src/agents/_shared/_messages.py
- Criteria:
  - 1 validate \| validate \| a known tool; arguments a JSON object matching its schema
  - 2 auth \| authenticate \| the caller is a known identity
  - 3 scopes \| authorize \| its own tools only
  - mail only to sales, the Email Agent only with an approved approval_id, Human Approval only about a pending one
  - no outbound text that leaks (keys, attack text, foreign addresses)
  - 4 rate limit \| rate_limit \| per identity and tool, per minute
  - 5 audit \| audit \| every call, allowed or refused, into brd.audit
  - 6 execute \| execute \| the MCP call with a timeout; a failure comes back as a value
- Outcome: built before the project was adopted
